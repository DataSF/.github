## Hi there! :wave:

This is the GitHub org for [DataSF](https://www.sf.gov/departments--city-administrator--datasf) (Office of the Chief Data Officer), the main data team for the City and County of San Francisco. Our team builds data infrastructure, pipelines, and reporting to support the city's vast data needs. We also publish hundreds of public datasets on San Francisco's [Open Data Portal](https://data.sfgov.org/) and help with data science work and program evaluation.

We currently build and maintain three major data platforms:

- [ODP (Open Data Portal) :mag_right:](https://data.sfgov.org/) - The City's public data portal, running on Socrata
- [IDP (Internal Data Portal) :office:](https://data.sfgov.org/) - A staff-only, internal version of the public data portal, also running on Socrata
- [UDP (Unified Data Platform) :snowflake:](https://app.snowflake.com/) - A centralized, citywide platform for data integration and analytics, built on Snowflake

You can learn more about DataSF on the [city's website](https://www.sf.gov/departments--city-administrator--datasf) or on [our blog](https://datasf.substack.com/). If you need help with a data asset or have an issue with one of the platforms we manage, please reach out via email at [support@datasf.org](mailto:support@datasf.org).

> [!NOTE]
> Most of the public repos on this GitHub are archived, but that doesn't mean DataSF is defunct. We're hard at work building internal infrastructure and projects, mostly around the UDP.
